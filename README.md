# SMP-Need

A modern, full-stack mini social media platform with user profiles, posts,
comments, likes, follows, direct messages, video calling, screen recording,
notifications, polls, and analytics.

**Stack**
- **Backend:** Python 3.11+, Django 4.2, Django REST Framework, Channels (WebSockets), SimpleJWT
- **Frontend:** HTML5, CSS3, vanilla JavaScript (ES6+), WebRTC, MediaRecorder API, Service Workers
- **Database:** SQLite (dev), PostgreSQL (prod)
- **Auth:** JWT (access + refresh)
